# ianarts-website

A custom web platform and digital gallery built to showcase and sell original artwork. This project serves as both an e-commerce storefront and a web development portfolio piece.

**Core Features**
* Digital Gallery: High-resolution image displays categorizing charcoal drawings, paintings, and anime-inspired artwork.
* E-Commerce Integration: Shopping cart functionality and secure checkout for purchasing original pieces.
* Social Integration: Direct links to my dedicated art Instagram and contact forms for commissions.
* Responsive Design: Optimized viewing experience across desktop and mobile devices.
